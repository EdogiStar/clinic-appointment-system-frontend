# 🏥 Clinic Appointment System – Frontend

A modern and responsive frontend for a Clinic Appointment System that allows patients, doctors, and administrators to manage appointments and related healthcare activities through an intuitive web interface.

## ✨ Features

- 🔐 User authentication
- 👤 Patient dashboard
- 👨‍⚕️ Doctor dashboard
- 📅 Appointment booking and management
- 🗓️ Doctor availability
- 🔔 Notifications
- 🛡️ Role-based access
- 📱 Responsive design

## 🛠️ Tech Stack

- **React.js**
- **Vite**
- **Tailwind CSS**
- **JavaScript**
- **Axios**
- **React Router**
- **Sonner**
